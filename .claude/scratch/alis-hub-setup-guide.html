Getting Started with ALIS Hub

This will get the Account Health and Team AM dashboards running on your computer. About 10 minutes, most of it just waiting for a one-time install. No technical background needed — just follow along in order.

Stuck anywhere? Stop and message Aaron rather than guessing — happy to hop on a quick call.

Before you start

  • 1Your own ALIS login — the email/username and password you already use. This is personal to you, nothing to share.
  • 2A HubSpot token from Aaron — ask him directly (Slack or in person, not email). You'll paste it in once during setup.
  • 3The zip file Aaron sent you — alis-hub.zip. Save it somewhere you'll find it, like your Desktop or Downloads.

Setup steps

1

Install Node.js (one-time, ~2 min)

This is the engine the app runs on.

Go to nodejs.org, download the button labeled LTS, and run the installer — click Next through the defaults— open the .pkg and click Continue through the defaults. Already have Node.js? Skip this.

2

Unzip the app folder

On your Desktop, create a new folder named ALIS Hub (right-click an empty spot → New → Folder). Move alis-hub.zip into it, then right-click the zip and choose Extract All — make sure it extracts into that same ALIS Hub folder, not somewhere else.

Keeping everything in one folder means the app's files won't end up scattered loose across your Desktop.

Move alis-hub.zip to wherever you want the app to live (Desktop is fine), then double-click it. macOS unzips it automatically into a new alis-hub folder right next to the zip — that folder is the app.

3

Double-click start.bat

Open start.command

Inside the ALIS Hub folder, double-click start.bat. A window will pop up.

Inside the alis-hub folder, right-click start.command and choose Open (just this first time — macOS blocks double-clicking a file downloaded from the internet until you approve it once). Click Open again in the popup. A Terminal window appears.

Why right-click the first time: macOS calls this "Gatekeeper" — it flags anything not from the App Store. Opening it this one way tells your Mac to trust this file going forward; every time after this, a normal double-click works fine.

The first time, it will install a few things it needs (can take a few minutes — text scrolling by is normal), then ask you a handful of questions one at a time, then start the app and open your browser automatically.

4

You're in

Your browser opens on its own to the dashboard. If it doesn't, go to http://localhost:5173 yourself.

A second window titled "ALIS Hub" stays open in the background — leave it running. Close it when you're done for the day to stop the app.

The Terminal window stays open in the background — leave it running. Close it when you're done for the day to stop the app.

If something goes wrong

"Node.js doesn't seem to be installed" — go back to Step 1.
Nothing happens when you double-click start.bat — try right-click → Run as administrator.
macOS says the file "cannot be opened" or "is from an unidentified developer" — that's Gatekeeper again. Right-click start.command → Open → Open, same as Step 3.
A dashboard section is empty — normal on first use, click Refresh.

Anything else — copy the exact message you're seeing and send it to Aaron. Screenshots help a lot.
